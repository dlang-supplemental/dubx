= Changelog

== 0.3.4 (2026-08-06)

* `dubx local <args…>` proxies optional `dubproxy` (private/mirror packages into `~/.dub/packages`).
* `dubx which` also reports `dubproxy`; missing-tool hints prefer path/git/`add-local` first.

== 0.3.3 (2026-08-06)

* `dubx publish <args…>` is an opaque passthrough to `dub-publish` (bare `publish` → dub-publish help).
* Top-level short aliases (`login`, `register`, …) remain; only remaps listed in `runPublish` may diverge later.

== 0.3.2 (2026-08-06)

* Fix `install.ps1` parse error in PATH hint lines.

== 0.3.1 (2026-08-06)

* Fix Windows zip packaging; build `macos-x64` via LDC `--arch=x86_64` on `macos-latest`.

== 0.3.0 (2026-08-06)

* Multi-platform releases: `windows-x64`, `linux-x64`, `macos-x64`, `macos-arm64`.
* Installers: `install.ps1`, `install.sh`, `install.nu` (nushell PATH hints).
* Help: install section documents PowerShell / bash / nushell.
* prohelp `v0.2.2`.

link:changelog-details/2026-08-06 - multiplatform installers.adoc[Details]

== 0.2.1 (2026-08-06)

* Bare invocation shows progressive help (prohelp) and exits 2.
* Dependency: `openshellorg/prohelp` `v0.2.1` (`deps/prohelp`).

link:changelog-details/2026-08-06 - bare run prohelp.adoc[Details]

== 0.2.0 (2026-08-06)

* Windows release packaging: zip + `install.ps1` (User PATH).
* GitHub Release workflow: stable on `v*` tags; **rolling** prerelease on `main`.
* Winget update CI (`dlang-supplemental.dubx`) gated on `WINGET_TOKEN`.
* `dubx version` reads `VERSION` / release stamp.

link:changelog-details/2026-08-06 - windows release packaging.adoc[Details]

== 0.1.0 (2026-07-31)

* Initial `dubx` meta-CLI: route build verbs to `redub` (fallback `dub`) and registry verbs to `dub-publish`.
* `dubx which` reports backend discovery.
* Escape hatches: `dubx redub|dub|dub-publish …`.
